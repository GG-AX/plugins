# GG AX 플러그인 목록 (마켓플레이스 `gg-ax`)

Claude Code 플러그인 목록입니다. 처음 한 번 연결하고, 필요한 플러그인만 설치합니다.

```
/plugin marketplace add GG-AX/plugins
/plugin install deck-kit@gg-ax
/plugin install project-notion@gg-ax
/plugin install costing-kit@gg-ax
```

| 플러그인 | 내용 | 저장소 |
| --- | --- | --- |
| `deck-kit` | HTML 발표 덱 키트 | [GG-AX/deck-kit](https://github.com/GG-AX/deck-kit) (공개) |
| `project-notion` | 개발 프로젝트 노션 관리 — AX DEV 팀만 설치 가능 | GG-AX/project-notion (비공개) |
| `costing-kit` | 코스팅 옵션 보드 키트 — 바이어 원본으로 AI 착샷, 오리지널·옵션 비교 HTML | [GG-AX/costing-kit](https://github.com/GG-AX/costing-kit) (공개) |

새 플러그인은 `.claude-plugin/marketplace.json`에 한 줄 추가합니다.
